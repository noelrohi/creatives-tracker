Launchpad v2 concept

Create Meta campaigns without learning every Meta setting first.

Launchpad v2 helps a new teammate create a complete paused Meta draft: a new campaign, a new ad set inside it, and ads using selected creatives. Instead of choosing every Meta setting manually, the tool copies those settings from an approved existing campaign/ad set.

Plain-English promise

The user does not need to understand pixels, conversion events, attribution, bid strategy, audiences, or placements on day one. Those settings are copied from the existing campaign/ad set.

1Choose an approved existing campaign/ad set.
2Add creatives and safe launch details.
3Create a paused setup for buyer review.

Why this helps a new user

Instead of asking a beginner to build a Meta campaign from scratch, Launchpad uses an existing campaign/ad set as the template. The new user focuses on choosing creatives, naming the launch, and checking the preview; the system handles the confusing setup details.

BENEFIT 01

Less cognitive load

No blank Meta forms. The user sees one guided path with only the decisions they can safely make.

BENEFIT 02

Fewer costly mistakes

Pixel, conversion event, audience, attribution, budget style, and placements are copied from the approved campaign/ad set instead of manually chosen.

BENEFIT 03

Cleaner handoff

Everything is created paused with links, names, warnings, and a checklist for the experienced buyer/cofounder to review before turning it on.

What are we actually creating?

Meta has a stack. Launchpad should make this stack visible without making the user configure every detail.

The simple mental model

  • Campaign = the top-level folder for the launch. Example: “June Hook Test”.
  • Ad set = the settings layer inside the campaign. This is where budget, audience, pixel/conversion event, placements, and optimization usually live.
  • Ads = the actual creative variations people see. Each selected creative becomes one paused ad.

What Launchpad copies

  • From the existing campaign: the broad campaign type/objective, when supported.
  • From the existing ad set: budget style, audience, placements, pixel/conversion event, attribution, and optimization settings.
  • From Adsolute: the selected creatives, names, final URL/UTMs, copy/headline/CTA.

Why copy instead of asking the user?

Because a beginner should not have to know which pixel, conversion event, audience, or attribution window is correct. The experienced person approves a source campaign/ad set once; the beginner reuses that structure safely.

What the new user avoids

Without Launchpad v2

  • Open Meta Ads Manager and face dozens of settings.
  • Guess which pixel, event, attribution, or placement to use.
  • Risk creating a live or incorrectly configured setup.
  • Ask the cofounder/media buyer for every routine launch.

With Launchpad v2

  • Pick from approved existing campaigns/ad sets with notes.
  • Attach creatives and review a plain-English plan.
  • Create everything paused and auditable.
  • Hand off a clean Meta setup for final activation.

The key product boundary

Launchpad should help beginners prepare launches safely. It should not pretend to make media-buying strategy decisions.

Copy setup structure, not performance

Tiny glossary for non-media-buyers

TERM

Pixel / conversion event

The tracking setup that tells Meta what result to optimize for, like purchases, leads, or signups. Beginners should not choose this manually.

TERM

Audience / placements

Who sees the ads and where they appear. Example: Instagram Reels, Facebook Feed, or a specific prospecting audience.

TERM

Paused

The objects exist in Meta, but they are not spending money yet. Someone still reviews and turns them on in Meta Ads Manager.

Example: what “do X flow” looks like

User sees

  • Choose existing template: “Creative Testing Campaign → Purchases Ad Set”
  • Select 6 UGC videos
  • Enter launch name: “June Hook Test”
  • Paste landing page URL
  • Review: “1 campaign, 1 ad set, 6 ads, all paused”
  • Click: “Create paused setup”

System handles

  • Copies campaign/ad set settings: objective, pixel/conversion event, attribution, audience, placements, budget style
  • Applies naming convention and UTM markers
  • Creates local audit trail and locked manifest
  • Creates/reconciles paused campaign, ad set, creatives, ads
  • Shows Meta links and buyer review checklist
