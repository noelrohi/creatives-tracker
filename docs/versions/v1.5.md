# V1.5 — Data & Workflow

## Bulk Performance Import

**Problem:** Manually entering ROAS/CPA/CTR for every ad set is tedious. Media buyers already export this from Meta.

**Solution:** CSV import flow for performance data.

### Flow
1. User clicks "Import from CSV" on an ad set detail or a global import page
2. Upload or paste CSV content
3. App parses columns, shows preview table
4. User maps CSV columns → our fields (ROAS, CPA, CTR, conv rate, spend, conversions, date start, date end)
5. User confirms → bulk insert into `performance_logs`

### Meta CSV Format
Typical Meta Ads Manager export columns:
- `Campaign name`, `Ad set name`, `Ad name`
- `Amount spent`, `Impressions`, `Reach`, `Clicks (all)`, `CTR (all)`, `CPC (all)`
- `Purchases`, `Cost per purchase`, `Purchase ROAS`
- `Reporting starts`, `Reporting ends`

### Column Mapping
| Meta Column | Our Field |
|---|---|
| Purchase ROAS | roas |
| Cost per purchase | cpa |
| CTR (all) | ctr |
| (calculated) purchases/clicks | conversionRate |
| Amount spent | spend |
| Purchases | conversions |
| Reporting starts | dateStart |
| Reporting ends | dateEnd |

### Implementation
- `src/lib/csv-parser.ts` — parse CSV string, detect columns, suggest mapping
- `src/lib/trpc/routers/performance-log.ts` — add `bulkCreate` mutation
- `src/app/(dashboard)/ad-sets/[id]/import/page.tsx` — import UI with preview + mapping
- Use `papaparse` for CSV parsing (`bun add papaparse @types/papaparse`)

## Duplicate / Clone

**Problem:** Creating similar creatives or campaigns from scratch is slow. Teams often iterate on what works.

**Solution:** One-click duplicate for any entity.

### Behavior
- Button on detail pages and list item context menus
- Creates a copy with name prefixed "Copy of..."
- All fields copied except id, createdAt, updatedAt
- Redirects to the new item's detail page
- For landing pages: duplicates the page but NOT versions (user adds versions separately)

### Implementation
- Add `duplicate` mutation to each tRPC router (adCreative, landingPage, campaignConfig, adSet)
- Add duplicate button to detail page headers
- Add duplicate option to list item hover/context actions

## Freeform Tags

**Problem:** Cross-cutting concepts (e.g., "Q1 launch", "teeth grinding", "competitor response") don't fit into existing structured fields.

**Solution:** Freeform tags on any entity.

### Schema
```sql
tags
  id, name (unique), color (optional), created_at

entity_tags
  id, entity_type (enum: ad_creative/landing_page/campaign_config/ad_set),
  entity_id, tag_id, created_at
```

### UX
- Tag input on every detail page (below the structured fields)
- Autocomplete from existing tags as you type
- Click to remove
- Optional color coding
- Filter by tag on list pages

### Implementation
- `src/schema/tag.ts` — tags + entity_tags tables
- `src/lib/trpc/routers/tag.ts` — CRUD + search + attach/detach
- `src/components/tag-input.tsx` — autocomplete tag component
- Add tag filter to creatives list page (nuqs param `?tag=...`)

## Comparison View

**Problem:** Hard to see *why* one creative outperforms another without side-by-side context.

**Solution:** Compare two ad sets (or creatives) side by side with their resolutions + performance data.

### UX
1. From any list page, select 2 items (checkbox)
2. "Compare" button appears
3. Opens comparison view: two columns showing all resolution fields + performance metrics
4. Differences highlighted
5. Shareable URL (`/compare?a=id1&b=id2`)

### Implementation
- `src/app/(dashboard)/compare/page.tsx` — comparison page
- Takes `?type=ad_set&a=id1&b=id2` via nuqs
- Fetches both items, renders side by side
- Color highlights for fields that differ
- Performance metrics shown as delta (↑ 1.2x ROAS, ↓ $5 CPA)

## A/B Test Tracking

**Problem:** No structured way to track which ad sets are variants of a test, or which variant won.

**Solution:** A/B test entity that groups ad set variants.

### Schema
```sql
ab_tests
  id, name, hypothesis, status (running/completed/paused),
  winner_variant_id (FK ad_sets, nullable),
  created_by, created_at, updated_at
```

Add to `ad_sets`:
```sql
ab_test_id (FK ab_tests, nullable)
variant_label (e.g., "control", "v1", "v2")
```

### UX
- New "A/B Tests" section in sidebar
- Create test → name + hypothesis
- Link existing ad sets as variants (with labels)
- View test: see all variants side by side with performance
- Mark winner

### Implementation
- `src/schema/ab-test.ts`
- `src/lib/trpc/routers/ab-test.ts`
- `src/app/(dashboard)/ab-tests/` — list + detail pages
- Update ad set detail to show linked A/B test
- Reuse comparison view for variant display
