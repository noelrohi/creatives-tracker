# V1.0 — MVP (Shipped)

## What's in V1

### Core
- Resolution schemas for 3 asset types: Ad Creatives, Landing Pages, Campaign Configs
- Ad Sets linking creative + landing page version + campaign config
- Performance logging (ROAS, CPA, CTR, conversion rate, spend, conversions, date range)

### UX
- Notion-style inline editing — click any field to edit, saves on blur
- Masonry grid + list view toggle for creatives (nuqs URL state)
- Dashboard with nav cards + recent activity feed
- Item-based list views for all entities
- Skeleton loading states, empty states, confirm dialogs

### Infrastructure
- Next.js 16 App Router, React 19, React Compiler
- Better Auth (email/password, org, admin plugins)
- Drizzle ORM + PostgreSQL
- tRPC v11 with superjson transformer + auth middleware
- Vercel Blob for file uploads (dev/prod path prefixing)
- shadcn/ui (radix-nova, olive base)
- nuqs for URL state management

### Schema
- `ad_creative` — name, assetUrl, format, angle, persona, awarenessLevel, hook, tone[], cta, landingPageId, notes
- `landing_page` + `landing_page_version` — versioned snapshots with pageType, heroCopy, benefits[], socialProofType[], funnelPosition
- `campaign_config` — objective, costCap, targetingMethod[], demographics, geos[], dailyBudget, placements[]
- `ad_set` — links creative + LP version + campaign
- `performance_log` — metrics attached to ad sets
