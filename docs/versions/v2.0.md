# V2.0 — Agent Layer

## Overview

V2 turns the resolution database into an intelligence layer. AI agents can read from and write to the resolution data, enabling automated analysis, brief generation, and eventually autonomous creative production.

---

## Auto-Suggest Resolutions

**Problem:** Filling out resolution fields for every creative is manual work. The AI should be able to look at a creative and suggest the right tags.

**Solution:** When a user uploads a creative asset, AI pre-fills resolution fields.

### How It Works
1. User uploads image/video to a creative
2. System sends asset to Claude's vision API
3. Claude analyzes the creative and returns suggested values for: format, angle, persona, awarenessLevel, hook, tone, CTA
4. Suggestions appear as ghost values in the inline fields
5. User accepts (click) or overrides (type)

### Implementation
- `src/lib/ai/suggest-resolution.ts` — sends asset + prompt to Claude API, returns structured JSON
- Server action or tRPC mutation triggered on asset upload
- Frontend shows suggestions as dimmed pre-fills with "Accept" action
- Uses Claude's structured output (tool use) for reliable field extraction

## Pattern Detection

**Problem:** Manual review of what angles/tones/awareness levels correlate with high performance. With enough tagged data, this should be automated.

**Solution:** Automated analysis that surfaces what's working.

### Insights Generated
- "**Clinical tone** creatives have 2.3x higher ROAS than **casual** on average"
- "**Problem-aware** targeting outperforms **unaware** by 40% on CPA"
- "Creatives with **sleep quality** angle consistently beat **facial symmetry**"
- "Landing pages with **before/after social proof** convert 1.8x better"

### How It Works
1. Scheduled or on-demand analysis
2. Query all ad sets with performance data
3. Group by resolution field values (tone, angle, awareness, etc.)
4. Calculate aggregate metrics per group
5. Surface statistically meaningful differences
6. Present as a dashboard / insights page

### Implementation
- `src/lib/ai/pattern-analysis.ts` — queries DB, computes aggregates, formats for display
- `src/app/(dashboard)/insights/page.tsx` — insights dashboard
- Could run as a cron job or triggered manually
- Start simple: SQL aggregates. Graduate to Claude analysis for nuanced patterns.

## Brief Generator

**Problem:** Once you know what works, turning that into a new creative brief is still manual.

**Solution:** AI generates creative briefs based on top performers.

### Flow
1. User clicks "Generate Brief"
2. Selects constraints: target persona, awareness level, format
3. System pulls top-performing resolutions matching constraints
4. Claude generates a brief: suggested angle, hook, tone, CTA, landing page recommendations
5. User can save as a "Brief" entity or export

### Implementation
- `src/lib/ai/generate-brief.ts` — pulls top resolutions, sends to Claude with system prompt
- `src/schema/brief.ts` — optional: persist generated briefs
- `src/app/(dashboard)/briefs/page.tsx` — brief list + generation UI

## Competitor Analysis

**Problem:** Competitors are running ads too. We should tag their creatives with the same resolution framework to compare strategies.

**Solution:** Tag competitor creatives with resolutions, compare to ours.

### Schema Addition
Add to `ad_creative`:
```sql
is_competitor BOOLEAN DEFAULT false
competitor_brand TEXT (nullable)
source_url TEXT (nullable) -- where we found it (Meta Ad Library, etc.)
```

### UX
- Toggle on creative: "This is a competitor creative"
- Set competitor brand name
- All resolution fields work the same
- Filter list view by competitor vs ours
- Comparison view: our top performers vs competitor creatives

## Retrieval API

**Problem:** External agents and tools need to query our resolution database for context when generating new creatives.

**Solution:** API endpoint that agents can query.

### Endpoints
- `GET /api/resolutions?type=ad_creative&tone=clinical&awarenessLevel=problem_aware`
- `GET /api/resolutions/top?metric=roas&limit=5`
- `GET /api/resolutions/patterns` — returns aggregated insights

### Implementation
- New tRPC router or REST API routes
- API key auth for external access
- Rate limiting
- Returns resolution data + performance metrics
